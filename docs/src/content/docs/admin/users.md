## サイトとユーザー

- 複数のサイトと複数のユーザーを扱えます。ユーザーごとのワークスペースは持たず、全ユーザーが同じサイトの情報を見ます。
- ユーザーのロールはadminとmemberの2つです。adminだけがユーザー管理（追加、ロールの変更、削除など）を行えます。それ以外の操作に差はありません。

ユーザーの追加のしかたはログイン方式で違います。[パスワードでログインする](/querune/admin/password/)と[OIDCでログインする](/querune/admin/oidc/)を参照してください。

## ロール

| ロール | できること |
| --- | --- |
| admin | すべての操作と、ユーザー管理（追加・招待リンクの再発行・パスワードの再設定・多要素認証のリセット・セッションの失効・ロールの変更・削除） |
| member | ユーザー管理以外のすべての操作 |

全ユーザーが同じサイトの情報を見ます。サイトごと・ユーザーごとに見られる範囲を分ける機能はありません。最後のadminのロールは変更できず、削除もできません。自分自身は削除できません。

ユーザー管理のAPIは[ログインとユーザー管理](/querune/reference/auth/)を参照してください。
