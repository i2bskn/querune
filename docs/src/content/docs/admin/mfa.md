---
title: 多要素認証
description: パスワード方式で使えるパスキー・セキュリティキー・認証アプリ（TOTP）と、必須にする範囲。
---

パスワードでログインする場合は、パスワードに加えてパスキー（セキュリティキーを含む）か認証アプリ（TOTP）で確認できます。OIDCの場合は、IdP側の多要素認証の設定に従います。

| 方式 | 使えるようにする設定 |
| --- | --- |
| パスキー・セキュリティキー | `APP_ORIGIN`にQueruneのURLのオリジンを設定します。`https://`で始まり、パスを含まない値にします。それ以外の値ではパスキーが使えません（エラーにはなりません） |
| 認証アプリ（TOTP） | `PASSWORD_MFA_KEY`に`openssl rand -base64 32`で生成した値をシークレットとして設定します |

- 何も設定しなければ多要素認証は使えず、これまでどおりパスワードだけでログインします。
- パスキーは`APP_ORIGIN`のホスト名に結び付きます。ドメインを変えると登録済みのパスキーは使えなくなります。
- `PASSWORD_MFA_KEY`を変えると登録済みの認証アプリが使えなくなります。その場合は復旧コードでログインして登録し直します。`JWT_SECRET`とは別に控えておいてください。

## 登録と解除

ログイン画面の「多要素認証の設定」（`/auth/mfa/manage`）から登録します。メールアドレスとパスワードを入れてから、パスキーか認証アプリを登録します。

- 登録すると復旧コードが8個表示されます。表示されるのはこの1回だけです。認証端末とは別の場所に保存してください。各コードは1回だけ使えます。
- 認証方法の追加・入れ替え・解除には、パスワードと登録済みの認証方法（または復旧コード）が必要です。
- 端末をなくしたときは、ログインの確認画面の「復旧コードを使う」から復旧コードを入れます。認証方法を入れ替えることもできます。最後の1個を使うと、そのまま新しい認証方法の登録に進みます。
- adminがパスワードを再設定しても、そのユーザーの認証方法は残ります。
- adminはユーザー管理の「多要素認証をリセット」で、ほかのユーザーの多要素認証をリセットできます。認証方法と復旧コードがすべて削除され、そのユーザーのセッションとMCPの接続も切れます。パスワードは残ります。
- リセットした後は、パスワードだけで新しい認証方法を登録できます。本人であることを確かめてからリセットし、すぐにログインして登録してもらってください。端末と一緒にパスワードも漏れたおそれがあるときは、パスワードも再設定します。
- 自分自身の多要素認証はリセットできません。adminが1人だけでそのadminが認証方法と復旧コードをすべてなくしたときは、D1のMFAの行を直接削除します。手順は[workers-app-coreのドキュメント](https://docs.i2bskn.com/workers-app-core/guides/password-mfa/#when-the-only-admin-is-locked-out)を参照してください。
- adminはパスワードと多要素認証の両方をリセットすれば、そのユーザーとしてログインできます。多要素認証はadminからユーザーを守るものではありません。

## 必須にする範囲

`PASSWORD_MFA_POLICY`で、多要素認証を必須にする範囲を決めます。

| 値 | 動作 |
| --- | --- |
| `optional`（既定） | 必須にしません。登録したユーザーだけが、ログインのたびに確認します |
| `admins` | adminは登録しないとログインできません |
| `all` | 全員が登録しないとログインできません。初期設定で作る最初のadminも含みます |

- `admins`と`all`では、`APP_ORIGIN`か`PASSWORD_MFA_KEY`の少なくとも一方が必要です。どちらもないと、すべてのリクエストが500になります（[設定エラーになったとき](/querune/admin/configuration/#設定エラーになったとき)）。
- パスキーだけを使う設定で`all`にした場合は、初期設定の画面を`APP_ORIGIN`のURLで開いてください。
- 設定はパスワードでログインし直したときに効きます。ログイン中のセッションとMCPの接続は切れません。セッションの更新でも確認は求められません。
- 確認の画面では、1回の確認につき5回まで入力できます。認証アプリのコードを何度も間違えると、そのユーザーの認証アプリでの確認にしばらく待ち時間がかかります。待っている間もパスキーと復旧コードは使えます。
