## 手順

1. Google Cloudでサービスアカウントを作り、鍵を`GOOGLE_SERVICE_ACCOUNT_KEY`に設定します（[Search ConsoleとGA4をつなぐ](/querune/getting-started/google/)）。
2. 管理画面の『すべてのサイト』でサイトを追加し、Search ConsoleのプロパティとGA4のプロパティIDを設定します。
3. サイトの画面の『データの取り込み』で期間を選んで取り込みます。以降は毎日、直近の日が自動で取り込まれます。
4. AIからQueruneのMCP（`https://<デプロイ先>/mcp`）に接続し、承認画面でログインして許可します。
5. AIに「今週のサイトの状況は？」「次は何を書く？」のように話しかけます。AIは実績と前回までのメモを読み取り、振り返りと次の行動を一緒に検討します。

## AIにできること

接続したAIは、取り込んだ実績と記事・メモを読み取れます。記事とメモはAIからも登録・編集できます（削除は管理画面だけ）。集計と指標の計算はサーバーで行い、AIは説明と検討を受け持ちます。

使えるツールと、接続の認可の仕組みは[MCP](/querune/reference/mcp/)を参照してください。
